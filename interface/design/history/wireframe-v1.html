What this demo shows

A bank's AI assistant gets real customer requests. Each one goes through a guard server that checks the question, the drafted answer, and any money movement. You see what the customer would get with and without guardrails.

3Compare and prove

Unprotected and protected replies side by side, with an audit record for every decision.

Five-minute presenter script

  1. Run Branch hours. Normal questions still get normal answers.
  2. Run Mutual fund. Advice is stopped before the assistant even writes a reply.
  3. Run Fund pick in answer. Even if the AI drafts something risky, the output check catches it.
  4. Run New account transfer. The guard blocks the payment and the balance does not change.
  5. Run Refund promise. It slips through. Turn on the refund policy and run it again: blocked, with no code release.
  6. Press Run all tests and open the Audit trail to close.

Policies on the guard server

Built-in rules ship with the bank. Custom policies are written by compliance in plain English and switched on without a code release.

PolicyWhat it stopsChecked atStatus
Investment adviceProduct or crypto recommendationsInput, outputLive
CommitmentsLocking rates, waiving feesInputLive
Fair treatmentBiased or demeaning repliesOutputLive
Customer dataCard numbers, one-time codes, national IDsInputLive
Payment riskTransfers from new accounts on new devicesPaymentLive
Prompt attacksAttempts to override rulesInputLive
Refund promises Custom

Rule: The assistant must never admit fault or promise a refund. Only a human agent can approve one.

When it fires, the reply becomes: "I'm sorry about this. I've passed your case to our disputes team, who will contact you within two working days."

Region-specific wording is set per region. Every replaced sentence is saved to the audit trail.
