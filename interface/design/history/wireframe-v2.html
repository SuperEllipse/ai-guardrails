What this demo shows

A bank's AI assistant gets real customer requests. Each one goes through a guard server that checks the question, the drafted answer, and any money movement. You see what the customer would get with and without guardrails, and how compliance can close a gap by writing a new policy.

1Pick a risk

Risk areas are listed on the left of the live screen, each with one to three test requests.

2Watch the check

The pipeline on the right lights up and shows exactly where the request was stopped.

3Close a gap

When a risk gets through, write a custom policy, test it, deploy it, and run the test again.

Five-minute presenter script

  1. Run Branch hours. Normal questions still get normal answers.
  2. Run Mutual fund. Advice is stopped before the assistant even writes a reply.
  3. Run Fund pick in answer. Even if the AI drafts something risky, the output check catches it.
  4. Run New account transfer. The payment is stopped and the balance does not change.
  5. Run Refund promise. It gets through: a gap. Press Close this gap.
  6. In Custom policies, read the rule, press Test rule, then Deploy. Press Run the gap test again: blocked.
  7. Press Run all tests and open the Audit trail to close.
